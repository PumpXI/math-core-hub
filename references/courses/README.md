# Referencias académicas de Kepler

Esta carpeta contiene cartas oficiales, libros base, prácticas y exámenes usados como referencia para construir el contenido académico de Kepler.

Reglas de uso:
- No copiar texto literal extenso de libros ni cartas.
- Usar las fuentes para definir temario, profundidad, secuencia y tipos de ejercicios.
- Todo el contenido final de Kepler debe escribirse en español claro, original y adaptado al estilo de la plataforma.
- Las cartas oficiales tienen prioridad sobre los libros cuando haya diferencias de cobertura.
- Los libros sirven como apoyo conceptual y para nivel de ejercicios.
- Cada curso debe tener un `resumen-temario.md` antes de generar contenido en código.

Restricciones importantes:
- Cálculo I tiene estructura congelada: no cambiar módulos, temas ni slugs salvo orden explícita del usuario.
- Mantener el slug `precalculo:numeros-reales`.
